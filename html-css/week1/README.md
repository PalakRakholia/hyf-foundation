## Order Form

This is my `Order Form project` for the HTML and CSS assignment.

The goal of the task was to recreate the provided Figma design using HTML and CSS while making sure the form works well on both desktop and mobile screens.

### What I Built

- Order form based on the provided Figma design
- Semantic HTML structure
- Responsive layout for desktop and mobile screens
- CSS styling using class selectors
- Properly formatted and structured HTML and CSS
- Layout and styling matched to the provided design

### Technologies Used

- HTML5
- CSS3
- Responsive Web Design

### Design

The project was built based on the provided [Figma design](https://www.figma.com/design/VwksDkp1vSPhpfa62LWIAz/HTML-CSS-session1?node-id=0-1&p=f&t=80kwJhl6O5jFMqrH-0).

### What I Learned

Through this assignment, I practiced creating semantic HTML, using CSS class selectors, and building responsive layouts. I also learned how to use a design as a reference and translate its layout and styling into HTML and CSS.
