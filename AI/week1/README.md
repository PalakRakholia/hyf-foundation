## Personal Portfolio

This is my personal portfolio project for the HackYourFuture AI Week 1 assignment.

I created a simple page using HTML, CSS, and JavaScript with the help of GitHub Copilot.

### What I built

- Main header with my personal details and a `Surprise Me` button that changes the background to a random color
- `About Me` section
- A list of my `Skills` and `Education`, along with my past `Work Experience` and `Hobbies`
- Custom styling with CSS
- Responsive design for mobile and desktop screens

### Technologies Used

- HTML
- CSS
- JavaScript
- GitHub Copilot

### AI Support

I used GitHub Copilot while working on this assignment to help me create the HTML layout based on what I wanted, suggest better solutions when possible, and help me solve problems along the way.

I also reviewed and modified Copilot’s suggestions when they didn’t match my requirements or the assignment.
