## Git Week 1 Assignment

This is my Git Week 1 assignment for HackYourFuture. The main focus of this exercise was to practice the basic Git and GitHub workflow used for submitting assignments.

### What I Practiced

- Creating and working with Git branches
- Switching between branches
- Pulling the latest changes from `main`
- Creating and organizing folders and files
- Adding and committing files individually
- Writing meaningful commit messages
- Pushing changes to GitHub
- Creating a Pull Request from an assignment branch to `main`
