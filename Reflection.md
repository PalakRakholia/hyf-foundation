## Reflection

### Q1. Identify and share 3 new things you learned from AI in the above task.

1. I learned how to make my portfolio more interactive by using a dialog box to preview my artwork when an image is clicked.

2. I had the vision to add a `Surprise Me` button that would randomly change the header background to showcase different artwork. With the help of AI, I learned how to implement this idea using JavaScript.

3. I learned how to use CSS variables inside `:root` to define and reuse colors throughout my portfolio, which helped me maintain a consistent theme.

### Q2. Where did you have to tweak or correct Copilot’s suggestions to suit your needs?

1. I had to tweak GitHub Copilot’s suggestions, especially for CSS styling. For example, when I wanted a simple background with opacity, I preferred the commonly used `rgba(0, 0, 0, 0.45)` format, while Copilot sometimes suggested the newer `rgba(0 0 0 / 45%)` syntax. Although both are valid CSS, I preferred the more familiar syntax because it was simpler for me to understand. Overall, I often adjusted Copilot’s styling suggestions to keep my code simple and readable.

2. I created a general HTML layout for one section of my portfolio first. I then used that structure as a base for the other sections, with Copilot helping me replicate similar classes and layouts according to my requirements.

### Q3. How would you explain the difference between using Copilot to generate code for you vs. using it as an effective learning partner?

When I ask Copilot to create everything on its own, the result may not reflect my creativity and can sometimes be more complex than necessary. I can also lose the personal touch in my work. However, when I have a clear vision of what I want to build and use Copilot as a learning partner, it helps me understand new concepts, improve my code, and implement my own ideas more effectively.

### Q4. Identify 3 risks of relying too much on AI tools when learning at HackYourFuture.

1. **Weak basic foundations:** If I rely too much on AI to write HTML, CSS, and JavaScript, I may not properly understand the fundamentals. This can make it difficult to solve problems on my own.

2. **Lack of confidence:** If I always depend on AI to write code, I may lose confidence in my own coding abilities. I can also become dependent on AI for small tasks that I could learn to do myself in a few minutes.

3. **Less problem-solving practice:** When AI gives me the solution immediately, I may miss the opportunity to think through the problem, make mistakes, and learn from them. This can slow down my development as a programmer.
